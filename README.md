# Portfólio — Eduardo Lona

Portfólio pessoal desenvolvido para apresentar minha formação, experiência, projetos, competências técnicas e trajetória na área de tecnologia.

## Sobre

O projeto reúne em uma única experiência web informações profissionais e acadêmicas, com foco em oportunidades de **desenvolvimento de software** e **tecnologia da informação**.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Conteúdo do portfólio

- Apresentação profissional
- Sobre mim
- Formação acadêmica
- Experiência
- Projetos
- Tecnologias e habilidades
- Competências comportamentais
- Contato

## Estrutura

```text
Portifolio/
├── assets/
├── css/
├── js/
└── index.html
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador ou utilize um servidor local como o Live Server durante o desenvolvimento.

## Objetivo

Este portfólio funciona como um ponto central para apresentar minha evolução em tecnologia e reunir os projetos desenvolvidos ao longo da formação.
