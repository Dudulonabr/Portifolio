# Como colocar o visual no seu perfil

O perfil está pronto para copiar. Os banners e ícones já estão publicados, portanto você não precisa enviar imagens.

## 1. Criar o repositório do perfil

1. Abra https://github.com/new.
2. Em **Owner**, selecione **Dudulonabr**.
3. Em **Repository name**, escreva exatamente **Dudulonabr**.
4. Selecione **Public**.
5. Ative **Add README**.
6. Clique em **Create repository**.

## 2. Colocar o README

1. Abra o texto pronto: https://github.com/Dudulonabr/Portifolio/raw/refs/heads/main/docs/github-profile/README-COPIAR.md.
2. Copie todo o texto com **Ctrl+A** e **Ctrl+C**.
3. Volte para https://github.com/Dudulonabr/Dudulonabr.
4. Abra **README.md** e clique no **lápis** para editar.
5. Apague o conteúdo inicial e cole o texto copiado.
6. Clique em **Preview** para conferir.
7. Clique em **Commit changes**; use a mensagem `docs: adiciona apresentação profissional ao perfil`.
8. Se aparecer a opção, escolha salvar diretamente na branch **main** e confirme em **Commit changes**.
9. Abra https://github.com/Dudulonabr. O README deve aparecer na página principal.

Se preferir, após criar o repositório, volte à conversa e escreva **criei**. Assim eu consigo publicar o conteúdo preparado pelo acesso existente.

## 5. Descrições e temas

Para cada repositório, abra a página inicial e clique na **engrenagem ao lado de About**. Preencha **Description** e **Topics** com os valores preparados em [profile-settings.json](profile-settings.json). Salve em **Save changes**.

## 6. Capas ao compartilhar links

A pasta [social-previews](social-previews) contém seis capas PNG de **1280 × 640 pixels**, uma para cada projeto principal.

1. Abra a capa do projeto nessa pasta e baixe a imagem.
2. Abra o repositório correspondente.
3. Vá a **Settings**, em **General**, e procure **Social preview**.
4. Clique em **Edit** e em **Upload an image**.
5. Escolha a capa correspondente.

A capa aparece quando o link do repositório é compartilhado; não funciona como banner na página principal do perfil.
