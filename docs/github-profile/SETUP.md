# Configuração do perfil GitHub

Este diretório contém o README e os recursos visuais prontos para o perfil de **Dudulonabr**.

## Publicação do README do perfil

1. Criar o repositório público `Dudulonabr/Dudulonabr`.
2. Copiar `README.md` deste diretório para a raiz desse repositório.
3. Copiar a pasta `assets/` deste diretório para a raiz desse repositório.

## Apresentação

Os campos de nome, bio, localização, ordem dos projetos fixados, descrições e topics estão em `profile-settings.json`. O arquivo é uma proposta de configuração; sua presença aqui não aplica esses campos automaticamente.

Os banners ficam nos próprios repositórios, evitando dependência de serviços externos de estatísticas ou de geração de imagens. O perfil valoriza projetos existentes, a formação em andamento e os conhecimentos em desenvolvimento.

## Repositórios de estudo

Os projetos antigos possuem READMEs que explicam seu contexto acadêmico e apontam para o portfólio atual. Não é necessário apagar o histórico para apresentar os projetos principais.
