# Créditos dos recursos visuais

Identidade visual, capas dos projetos, botões, composição e animação de digitação preparados para Eduardo Lona.

Os ícones de Python, JavaScript, HTML, CSS e Java foram obtidos do projeto [Devicon](https://github.com/devicons/devicon), sob a licença MIT reproduzida em `icons/LICENSE`. Nomes e logotipos pertencem aos respectivos titulares. O símbolo de SQL é uma ilustração genérica de banco de dados.

A referência compartilhada de Gabrielle Souza Felix inspirou a organização do conteúdo e a presença de animação, tecnologias e contatos. O conteúdo profissional, a identidade e os projetos apresentados são os de Eduardo.
